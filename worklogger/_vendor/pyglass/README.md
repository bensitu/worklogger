Revision: `c12d91f1526badbe18f619ff893d2cdbbd86dac5`

Only the numerical refraction module is included. The Qt image import and
buffer conversion use PySide6 instead of PyQt6. Desktop capture, demo windows,
and the upstream widget framework are not included.
